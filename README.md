### With Aria, you can:

- Build and edit pages visually
- Manage content with the built-in CMS
- Manage design tokens, classes, variables, icons, fonts, and motion
- Use built-in Git and terminal tools
- Import content from WordPress or Markdown
- Use Aria's AI Engineer; BYOK

Aria works directly with your .astro files. There is no project conversion, proprietary format, or replacement Git workflow.

## Download

Aria is currently pre-v1 and builds are unsigned.


Unsigned preview downloads will be added after the first successful public build.


Unsigned builds may trigger security warnings on macOS and Windows.
Code signing and notarization are planned.

### First open:

MacOS: Gatekeeper blocks unsigned apps. In Finder, right-click Aria, choose Open, and confirm. You can also allow it in System Settings, Privacy & Security.

Windows: SmartScreen may say "Windows protected your PC." Click More info, then Run anyway.

Linux: `chmod +x` the AppImage and run it. Ubuntu 24.04 and newer need libfuse2:

```bash
sudo apt install libfuse2t64
```
